# BESTECH — демо цифрового двойника

Статический демо-стенд стадии «Строительство»: 3D-модель корпуса, 12 датчиков, телеметрия,
журнал аварий и пульт показаний. Всё считает браузер — ни сервера, ни базы, ни сборки.
Открывается двойным щелчком по `index.html` и хостится на любом бесплатном статическом хостинге.

Показывает то же, что боевой портал BESTECH на стадии строительства, но без кабинета
с документацией, ролей и мастерской выпуска чертежей: они работают с базой, файлами и Revit.

## Запуск локально

```powershell
# просто открыть файл
start index.html

# или отдать по HTTP (нужно для модулей, если браузер блокирует file://)
npx serve . -l 4321
```

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | разметка: шапка, вкладки, панели |
| `js/sim.js` | симулятор: датчики, пороги, дрейф и шум, сценарии, аварии, буфер истории |
| `js/model3d.js` | 3D-модель на three.js: каркас 36 × 18 м, метки датчиков, подсветка ферм |
| `js/charts.js` | графики SVG: линии, столбики, спарклайн |
| `js/app.js` | сборка экранов, вкладки, обработчики |
| `css/tokens.css`, `css/ui.css` | дизайн-система портала: темы «Бумага» и «Цианотипия» |
| `vendor/` | three.js и его модули, без CDN — стенд работает без интернета |

Симуляция повторяет поведение боевого стенда: значение сверяется с порогами проекта,
выход за порог открывает аварию, возврат в допуск её закрывает, а датчик без пакетов
дольше четырёх периодов опроса получает «нет связи». На объекте эти же экраны питает
шлюз: `POST /api/ingest/v1/readings` с ключом устройства.

## Сценарии для показа

Вкладка «Пульт показаний»: перегруз фермы Ф-2, перегрев бетона КЖ-3, мороз на захватке КЖ-1,
осадка марки ГМ-07, раскрытие трещины ТР-1, обрыв связи с ТП-1 и возврат в норму.
Рядом ручной ввод: ползунок задаёт значение любому датчику.

Кнопка «Сброс демо» в шапке очищает журнал и заново набирает историю за час — удобно
перед началом презентации.

## Публикация бесплатно

**Render (статический сайт, бесплатный тариф)** — в репозитории есть `render.yaml`:
Render → New → Blueprint → выбрать репозиторий. Бесплатные статические сайты не засыпают
и не ограничены числом запросов, в отличие от бесплатных web-сервисов.

**GitHub Pages:** Settings → Pages → Deploy from branch → корень ветки.

**Любой хостинг:** выложить папку целиком, точка входа `index.html`. Сборка не нужна.

## Чего стенд не делает

- Не хранит данные: перезагрузка страницы начинает историю заново.
- Не принимает показания извне — сеть не используется, API здесь только упомянут.
- Не показывает мастерскую, кабинет и документацию, это часть основного портала.
