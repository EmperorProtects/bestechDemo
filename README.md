# BESTECH — демо платформы

Статическая копия портала: кабинет заказчика, исходные данные, документация с чертежами
и цифровой двойник стройплощадки. Сервера, базы и сборки нет — всё считает браузер,
поэтому демо открывается двойным щелчком по `index.html` и бесплатно хостится
на любом статическом хостинге.

## Что показывает

| Экран | Адрес | Что внутри |
| --- | --- | --- |
| Вход | `#/login` | три роли: заказчик, ГИП, технадзор |
| Мои объекты | `#/assets` | три объекта на разных стадиях, фильтр по стадии, схемы и сроки |
| Лист объекта | `#/asset/2026-014` | показатели, стадии проекта, лента событий, паспорт |
| Исходные данные | `#/asset/2026-014/inputs` | комплектность, чего не хватает, ведомость документов, зона загрузки |
| Документация | `#/asset/2026-014/documents` | разделы ПД, версии, состояния, листы раздела |
| Лист чертежа | `#/asset/2026-014/documents/АР-05` | лист с рамкой и основной надписью по ГОСТ 2.104, маркеры замечаний и переписка нормоконтроля |
| Двойник | `#/twin/2026-014` | 3D-модель, 12 датчиков, телеметрия, журнал аварий, пульт показаний |

## Запуск локально

```powershell
start index.html          # просто открыть файл
npx serve . -l 4321       # или отдать по HTTP
```

## Из чего собрано

| Файл | Назначение |
| --- | --- |
| `index.html` | каркас страницы, всё остальное рисует JS |
| `js/app.js` | маршруты, сайдбар и шапка, экраны двойника |
| `js/screens.js` | экраны кабинета: вход, объекты, исходные данные, документация, лист |
| `js/data.js` | данные демо: объекты, разделы, листы, замечания, события |
| `js/sheet.js` | лист чертежа: рамка, основная надпись, план, разрез, ведомость |
| `js/sim.js` | симулятор датчиков: пороги, дрейф, шум, сценарии, аварии |
| `js/model3d.js` | 3D-модель корпуса 36 × 18 м на three.js |
| `js/charts.js` | графики SVG: линии, столбики, спарклайн |
| `css/tokens.css`, `css/ui.css` | дизайн-система портала, темы «Бумага» и «Цианотипия» |
| `vendor/` | three.js без CDN — демо работает и без интернета |

Двойник повторяет боевую логику: значение сверяется с проектными порогами, выход за порог
открывает аварию, возврат в допуск её закрывает, а датчик без пакетов дольше четырёх периодов
опроса получает «нет связи». На объекте те же экраны питает шлюз:
`POST /api/ingest/v1/readings` с ключом устройства.

## Сценарии для показа

Вкладка «Пульт показаний» в двойнике: перегруз фермы Ф-2, перегрев бетона КЖ-3, мороз
на захватке КЖ-1, осадка марки ГМ-07, раскрытие трещины ТР-1, обрыв связи с ТП-1 и возврат
в норму. Рядом ручной ввод: ползунок задаёт значение любому датчику. Кнопка «Сброс демо»
очищает журнал и заново набирает историю за час — удобно перед началом презентации.

## Публикация бесплатно

**Render:** New → Static Site (или Blueprint с `render.yaml`) → репозиторий → Publish Directory `.`,
Build Command пустой. Бесплатные статические сайты не засыпают и не ограничены числом запросов.

**GitHub Pages:** Settings → Pages → Deploy from branch → корень ветки.

**Netlify Drop:** перетащить папку на `app.netlify.com/drop`, ссылка появится сразу.

## Ограничения

- Данные не сохраняются: перезагрузка страницы начинает историю заново.
- Сеть не используется, показания никуда не уходят и ниоткуда не приходят.
- Загрузка файлов, скачивание PDF и ZIP показаны, но файлов не выдают.
- Мастерская выпуска чертежей и Revit остались в основном портале: они работают с базой,
  файлами и локальными сервисами.
